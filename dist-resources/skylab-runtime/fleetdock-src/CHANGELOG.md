# 变更日志

本项目遵循语义化版本。`0.x` 阶段的稳定公共入口会保持兼容；试验能力的调整会在此记录。

## 0.4.0

- PX4 控制遥测改为需求租约：连接后仅常驻低带宽安全状态，位置、速度、姿态和 Home 由任务、
  强类型事件订阅、手动控制或 WS 状态会话自动申请；同一路 MAVSDK 流按引用计数复用，业务 Demo
  和公共调用保持不变。
- 设备事件分发改为容量 256 的有界队列，高频同类遥测过载时保留最新事件；设备诊断新增事件积压、
  最高水位和丢弃计数。PX4 回调队列与 Python WS 待处理队列也保持有界。
- `fleetdock-server-drone` 新增 `--link-profile simulation|standard|low_bandwidth`，室内低速数传可以
  显式限制位置、姿态、速度和电池遥测频率。
- 修正连续航线在原生 Mission 与 SDK 平滑执行切换时可能释放本地位置流的问题；飞控拒绝遥测
  降频请求时继续使用默认频率并报告诊断，避免航线读取到不再更新的位置。
- `Plan(drone).takeoff(...)` 增加跨厂商物理完成协议；PX4 会依据运行期遥测自动选择飞控原生起飞
  或本地位置闭环，应用代码不传 MAVSDK/Offboard 策略，也不再必须显式 `unlock()`。
- PX4 本地位置起飞复用受控真机 Demo 的预发送、先建立控制、标准解锁与高度目标并发、安全边界、
  离地前单次回退和 Land 兜底；起飞、Mission、Land/RTL/紧急动作共享控制权仲裁。
- 新增强类型起飞状态、标准生命周期事件和稳定错误码；直接 `Drone.takeoff()` 继续保持即时接受语义。

## 0.3.0

- 标准运动控制统一使用 `CommandName.MOVE` 和强类型 `MoveTarget`，产品通过
  `supported_move_targets` 声明支持的坐标目标，不再维护重复的 `GOTO_GLOBAL/GOTO_LOCAL` 命令与能力。
- `Drone` 和 `DronePlan` 的 `goto_global()`、`goto_local()` 保留为 `move(...)` 的便捷入口；
  删除未生效的 `goto_local(..., speed=...)` 参数，避免调用方误以为速度已进入执行链。

## 0.2.0

- 增加产品集成成熟度、类型包标记和版本入口。
- 增加质量门禁、发布治理、支持矩阵、故障测试和渐进式 Quick Start。
- 明确即时设备命令与任务完成确认的语义边界。
- 全仓 mypy 和 85% 覆盖率作为发布门禁，重点保护任务、事件、设备生命周期和 PX4 安全路径。
