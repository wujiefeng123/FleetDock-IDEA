## 1. 证据等级

由低到高记录每项能力的证据，不得跨级推断：

| 等级 | 含义                                         |
| ---- | -------------------------------------------- |
| D0   | 只有文档或设计                               |
| D1   | 有公共接口或 ProductProfile                  |
| D2   | 有适配器实现及 Mock/注入测试                 |
| D3   | 在真实依赖下完成协议级自动测试               |
| D4   | PX4 SITL 或对应厂商仿真完成动作闭环          |
| D5   | 指定真机、固件和厂商 SDK 组合完成受控验收    |
| D6   | 有持续回归、故障注入、兼容矩阵和生产运维保障 |

“支持”至少要说明证据等级。`planned` 通常不高于 D1，`simulated` 不高于 D2，`beta` 应尽量达到 D4/D5。

## 2. 严重性

- P0：可能导致错误设备动作、安全事故、能力虚假声明、敏感信息泄漏或资源无法收回。
- P1：阻碍新手完成核心流程、跨品牌抽象泄漏、主要任务闭环缺失、质量门禁失败。
- P2：可维护性、文档、命名、示例组织或次要覆盖不足。

## 3. 九维评分

每项 0 ～ 5 分：5 为门禁完整且证据充分；4 为可用但有明确小缺口；3 为 Beta；2 为骨架/模拟；1 为设计；0 为缺失或误导。

1. 新手首次体验：安装到首个安全任务是否可在 15 分钟内完成。
2. Demo 简洁度：一句代码一个业务意图，Quick Start 建议不超过 80 行。
3. 公共 API 与协议隔离：业务代码是否无需厂商分支、原生 SDK 和坐标转换。
4. 能力真实性：声明、实现、成熟度、文档和证据是否一致。
5. 跨品牌/跨设备编排：混合 Fleet、能力筛选、计划和部分失败是否统一。
6. 任务与安全闭环：物理完成确认、取消、超时、重试、守卫和安全收尾。
7. 生命周期与可观察性：连接、重连、关闭、线程、订阅、日志和错误诊断。
8. 测试与真实集成：单测、契约、SITL、真机、故障注入和覆盖率。
9. 发布与兼容性：稳定 API、弃用、版本、构建、Wheel 重装和依赖矩阵。

总分只用于比较版本，不能覆盖 P0；存在 P0 时不得给出“生产可用”。

## 4. 必查清单

### 新手与 Demo

- Mock 首次运行不依赖外部厂商环境。
- 从 Mock 切到 PX4 时，计划和业务调用基本不变。
- Quick Start 按连接、动作、事件、计划、Fleet、诊断递进。
- 每个示例只解决一个问题；环境准备脚本与 SDK 用法示例分开。
- Demo 不手写 SDK 应承担的轮询、坐标转换、速度曲线、重试和异常返航。
- 高级 Scenario 明确标记，不作为复制模板。

### API 与能力

- 产品声明的每个命令都有实际成功路径，而不只是同名处理器。
- `has_capability()` 与运行时行为一致。
- 不支持能力在构建、诊断或执行前清楚暴露。
- 参数单位、坐标系、范围、可空语义和完成时机清楚。
- 厂商原始对象只作为可选高级入口。

### 跨设备编排

- 通用能力位于 `BaseDevice`，设备专属能力位于对应类型。
- 混合 Fleet 可按类别、产品和能力筛选。
- 同一步多设备执行结果能定位具体成员。
- 部分失败、fail-fast、取消和安全停止语义明确。
- 新品牌可通过 Profile、Registry、Factory 和 Adapter 扩展，不修改业务计划。

### PX4 协议链

- Python 飞行示例不通过 CLI 控制 PX4。
- 标准命令确实翻译到 MAVSDK/MAVLink。
- 本地位置、速度、GPS、高度和 yaw 坐标转换有数值测试。
- Mission、Offboard、遥测和传感器流共享清楚的连接与生命周期边界。
- 心跳、双向链路、断链、重连、MAVSDK server 退出和多机端口有处理。
- 不依赖厂商私有字段，或对私有依赖有隔离与兼容测试。

### 安全与生命周期

- 起飞前可检查定位、Home、健康和 armable。
- 即时响应不冒充物理动作完成。
- 遥测过期、低电量、禁区、限高、间距和 failsafe 可形成 SDK 策略。
- 取消默认执行安全停止；`close()` 不隐式冒充返航/降落。
- `close()` 幂等；失败初始化和托管对象所有权正确释放。
- 后台线程、事件、遥测和传感器订阅可观察且可终止。

### 质量与发布

- 公共类、枚举、数据对象和方法有合格中文说明。
- Ruff、mypy、单测、覆盖率和构建通过。
- PX4 client、任务执行和安全关键路径有重点覆盖。
- SITL 至少覆盖连接、解锁、起飞、移动/航线、取消、RTL 和降落。
- 受控真机结果记录机型、固件、MAVSDK 和环境。
- Wheel 重装、公共导出、版本、CHANGELOG、README 和支持矩阵一致。

## 5. 最终通过条件

### 新手可用

- 无 P0。
- 新手体验、Demo、API 隔离均至少 4 分。
- Quick Start 可运行且不直接调用厂商 SDK。

### PX4 Beta 可用

- 无能力声明与实现不一致。
- 核心控制链达到 D4，安全关键路径至少有注入测试和 SITL 证据。
- 单测、静态检查和构建通过；跳过的集成测试明确披露。

### 产品生产候选

- 无 P0/P1。
- 九维均至少 4 分。
- 目标机型达到 D5，并有故障注入、版本兼容矩阵和发布回归。
- 不因一个品牌的私有协议细节要求业务代码分支。
